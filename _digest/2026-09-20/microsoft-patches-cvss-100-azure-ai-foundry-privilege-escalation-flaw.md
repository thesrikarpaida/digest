Microsoft has released fixes for a maximum-severity privilege escalation vulnerability, CVE-2026-85889, in Azure AI Foundry. This flaw, with a CVSS score of 10.0, could allow an unauthorized attacker to elevate privileges over a network due to missing authentication for a critical function. Microsoft states that no customer action is required as fixes have been automatically applied.
