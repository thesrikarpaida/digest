SolarWinds has released security updates to address CVE-2026-28326, a high-severity flaw (CVSS 8.8) in Access Rights Manager (ARM) 2026.2 and prior versions. This vulnerability could lead to unauthenticated remote code execution due to a hard-coded key. All users of affected ARM versions are urged to apply the security updates immediately to prevent potential exploitation.
