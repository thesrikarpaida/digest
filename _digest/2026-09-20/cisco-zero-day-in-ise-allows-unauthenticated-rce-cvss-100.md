Cisco has issued a warning about a critical zero-day vulnerability, CVE-2026-76460, in its Identity Services Engine (ISE). This flaw, rated 10.0 on the CVSS scale, allows an unauthenticated, remote attacker to bypass authentication on an API endpoint, potentially leading to remote code execution. Cisco confirms active exploitation of this vulnerability, making immediate patching crucial for affected organizations.
