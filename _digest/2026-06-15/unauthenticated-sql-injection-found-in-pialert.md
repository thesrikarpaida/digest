> **Severity: CRITICAL**
{: .prompt-danger }

Project Black researchers have discovered an unauthenticated SQL injection vulnerability in Pi.Alert. This flaw allows an attacker to exploit the system without any prior authentication, potentially enabling them to extract the entire database. Users of Pi.Alert should be aware of this critical vulnerability and apply any available patches or mitigation strategies immediately.
