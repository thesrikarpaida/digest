SpecterOps released Blacklight, an open-source security research toolkit designed to discover and analyze AI agent artifacts on endpoints. This tool helps security teams assess exposure, guide decisions, and develop detection and hardening guidance for AI agent deployments. Developed with OpenAI's Trusted Access for Cyber program, Blacklight aims to illuminate the security implications of AI agents.
