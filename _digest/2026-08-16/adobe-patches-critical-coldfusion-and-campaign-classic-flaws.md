Adobe released security updates to address multiple critical vulnerabilities in ColdFusion, Commerce, and Campaign Classic. Most notably, CVE-2026-48362, a CVSS 10.0 operating system command injection flaw in ColdFusion, could lead to arbitrary code execution. These patches are crucial for preventing remote code execution and privilege escalation in affected environments.
