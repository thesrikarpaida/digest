A security researcher has released a new Windows zero-day exploit, 'LegacyHive,' which allows attackers to escalate privileges on up-to-date Windows systems. This vulnerability, described as a Windows User Profile Service arbitrary hive load elevation of privileges, enables attackers to gain administrative access. The public availability of a proof-of-concept (PoC) makes immediate attention to potential mitigations crucial for Windows administrators.
