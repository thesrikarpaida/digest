A new high-severity local privilege escalation (LPE) vulnerability, CVE-2026-8933 (CVSS 7.8), has been disclosed in Ubuntu's snap-confine. An unprivileged local user can exploit this flaw to gain root access and full control over affected systems. The vulnerability impacts default installations of Ubuntu Desktop 24.04, 25.10, and 26.04, posing a significant security risk to desktop users.
