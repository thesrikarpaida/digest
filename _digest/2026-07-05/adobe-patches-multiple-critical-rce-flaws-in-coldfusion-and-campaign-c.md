Adobe has released security updates addressing several critical vulnerabilities, including seven CVSS 10.0 flaws, in Adobe ColdFusion and Adobe Campaign Classic. These vulnerabilities could lead to arbitrary code execution, privilege escalation, arbitrary file system reads, and security feature bypasses. Organizations using these products are urged to apply the patches immediately to prevent exploitation.
