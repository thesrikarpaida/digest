Binarly researchers discovered six new vulnerabilities in U-Boot, a widely used bootloader for various embedded devices. Four flaws can cause device crashes, while two critical bugs allow an attacker to execute arbitrary code during the boot process by injecting a malicious image. These vulnerabilities could lead to stealthy firmware attacks, compromising device security and enabling persistent malware installation.
