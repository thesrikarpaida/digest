A new report by GitGuardian reveals that AI-assisted code commits are leaking secrets at approximately twice the rate of human-written code. This surge in 'secrets sprawl' is largely connected to AI-related credentials, exacerbating an existing identity problem. The rapid adoption of AI coding agents, while boosting productivity, introduces new security challenges by accelerating the exposure of sensitive credentials in development environments.
