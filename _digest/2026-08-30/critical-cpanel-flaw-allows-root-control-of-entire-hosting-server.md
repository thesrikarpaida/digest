cPanel has released patches for a critical security vulnerability, CVE-2026-65643, affecting domain parking and addon domain functionality in cPanel and WebHost Manager (WHM). This flaw could allow a single hosting customer to execute code as the root user, compromising the entire server. All supported versions of cPanel & WHM are impacted, requiring immediate updates.
