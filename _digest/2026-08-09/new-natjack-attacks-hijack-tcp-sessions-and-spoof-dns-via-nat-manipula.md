Security researcher Malcolm Stagg has disclosed a new attack class called 'NatJack,' which manipulates Network Address Translation (NAT) connection states. These attacks can hijack active TCP sessions, spoof DNS responses, expose mapped ports, and exhaust NAT tables. The affected behavior was found across independently developed NAT implementations, including Windows.
