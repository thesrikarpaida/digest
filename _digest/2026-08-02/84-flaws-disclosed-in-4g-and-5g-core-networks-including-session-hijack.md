An academic study has revealed 84 security vulnerabilities in 4G and 5G core networks, including a critical session hijacking flaw. These widespread vulnerabilities could enable denial-of-service (DoS) attacks and allow attackers to seize control of user network sessions. The findings, from Singapore's Nanyang Technological University, highlight significant security gaps in modern mobile network infrastructure.
