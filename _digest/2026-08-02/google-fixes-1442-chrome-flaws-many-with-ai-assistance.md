Google announced it fixed a remarkable 1,442 security bugs across Chrome versions 149, 150, and 151, a number exceeding the total flaws patched in the previous 23 updates combined. A significant portion of these fixes, particularly 1,072 bugs in versions 149 and 150, were attributed to the expanded use of artificial intelligence in vulnerability discovery. This demonstrates AI's growing impact on improving software security, though 370 flaws were still resolved in the latest patch.
