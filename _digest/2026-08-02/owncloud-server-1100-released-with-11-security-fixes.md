ownCloud Server 11.0.0 has been released, featuring a PHP 8.3 baseline, a stronger G2 code signing scheme, and 11 security fixes. This update addresses various vulnerabilities and improves the overall security posture of the self-hosted file synchronization and sharing platform. Users are strongly advised to upgrade to this version to benefit from the latest security enhancements and bug fixes.
