SpecterOps has released new Mythic extensions to simplify container-centric assessments, particularly for Kubernetes and Docker environments. These tools enable operators to wrap Mythic payloads in OCI-compatible containers and publish them to a self-hosted registry. This development enhances the Mythic C2 framework's capabilities for red teams and penetration testers conducting assessments in modern containerized infrastructures, offering more flexible and stealthy payload delivery options.
