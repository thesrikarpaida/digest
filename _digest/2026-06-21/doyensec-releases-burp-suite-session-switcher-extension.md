Doyensec has released 'Session Switcher,' a new Burp Suite extension designed to streamline authorization testing. This tool allows security testers to easily save and switch between different HTTP sessions with a few clicks directly from the request editor. It addresses the tedious and error-prone process of manually swapping cookies and headers during checks for privilege escalation, IDORs, and other access control issues, significantly improving efficiency for web application security assessments.
