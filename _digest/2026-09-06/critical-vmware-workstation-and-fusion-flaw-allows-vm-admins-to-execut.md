Broadcom has issued security updates for VMware Workstation and Fusion, addressing a critical integer-overflow vulnerability (CVE-2026-59346) with a CVSS score of 9.3. This flaw could allow a local attacker with elevated privileges within a virtual machine to execute arbitrary code on the host system. Users are advised to update their VMware products to the latest versions.
