Cisco has released patches for a critical security flaw (CVE-2026-20212) affecting 10 Silicon One-based Nexus 9000 switches. This vulnerability allows an unauthenticated, remote attacker to execute code as root. Additionally, an IOS XR hardening release bundles seven CVEs, two of which are rated 9.8, with no workarounds available for any IOS XR version. Immediate patching is crucial for affected devices.
