SpecterOps introduces TATS (Token Analysis and Tracking System), a new tool designed to collect, store, decode, analyze, and visually track OAuth token exchanges. TATS addresses the challenges of tracking OAuth tokens, especially within the Microsoft ecosystem, but is compatible with any OAuth implementation. This tool provides valuable insights for security professionals dealing with complex identity and access management scenarios.
