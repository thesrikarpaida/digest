A new Linux kernel privilege escalation vulnerability, CVE-2026-43503 (CVSS 8.8), dubbed 'DirtyClone,' has been publicly demonstrated. This flaw, part of the DirtyFrag family, allows a local user to corrupt file-backed memory via a cloned network packet, leading to root access. The vulnerability has since been patched in the kernel.
